# 핵심 플레이 UX와 화면 가리기 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 진행을 잃지 않고 규칙을 쉽게 찾으며, 필요할 때 화면을 즉시 흐리게 가릴 수 있는 게임을 만든다.

**Architecture:** 게임 동작과 저장은 공용 `useGame`에서 처리한다. 도움말은 기존 패널을 재사용하고, 가리기는 게임 상태와 분리된 네이티브 dialog로 구현한다. 두 셸은 같은 동작을 호출하며 레이아웃을 새로 짜지 않는다.

**Tech Stack:** React 19, TypeScript, Vite, 플레인 CSS, Vitest, 브라우저 localStorage·dialog. 실측은 저장소 밖의 Playwright WebKit·Chromium을 사용한다.

## Global Constraints

- 승인 설계: [핵심 플레이 UX와 화면 가리기](../specs/2026-10-21-core-ux-design.md).
- 검토 기준: `f07c8a3921246a7aa0f65c76cd2115e97c784b03`. 구현 시작 시 최신 main과 차이를 먼저 확인한다.
- 현재 작업 브랜치는 과거 수정 위에 문서만 더한 상태다. 구현 전에 main 변경을 보존해 통합하며 강제 초기화하지 않는다.
- UI 문자열·주석은 한국어. 파일은 500줄 이하. 새 런타임 의존성·CSS 프레임워크·jsdom을 추가하지 않는다.
- 모바일은 새 행을 만들지 않는다. 게임 이름과 기존 보드 크기, 44px 상단 버튼 터치 영역을 지킨다.
- `MOBILE_QUERY`와 CSS 미디어 쿼리는 일치해야 한다. `repeat(var(`를 사용하지 않는다.
- 진행은 기기 안의 현재 사건 하나만 저장한다. 완료 기록·계정·순위 데이터와 분리한다.
- 가림은 **전체 화면을 강하게 흐리고 `계속하기` 버튼만 표시**한다. 새로고침 후 가림 유지·자동 가리기는 제외한다.
- 퍼즐 규칙·생성기·기존 최초 해결 점수 정책은 바꾸지 않는다.
- 테스트는 실제 마크업과 상태를 검사한다. CHANGELOG 안의 같은 문자열을 성공 근거로 삼지 않는다.

```js
async function openCase(page, mobile, n, seed) {
  const menu = () => page.locator(mobile
    ? '.mtop > button[aria-label^="메뉴"]'
    : '.controls > button[aria-label^="더보기"]').click();
  if (mobile) await menu();
  const pick = page.getByRole('button', { name: new RegExp(`\\(${n}×${n}\\)`) });
  if (await pick.getAttribute('aria-pressed') !== 'true') {
    await pick.click();
    if (mobile) {
      await page.waitForFunction(() => !document.querySelector('.sheet[open]'));
      await menu();
    }
  }
  if (!mobile) await menu();
  await page.getByRole('textbox', { name: '시드 입력' }).fill(seed);
  await page.locator('.sheet[open] .seedbox button[type=submit]').click();
  if (await page.locator('.sheet[open]').count())
    await page.locator('.sheet[open] .sheet-x').click();
  await page.waitForFunction(() => !document.querySelector('.sheet[open]'));
}
```

**Interfaces:** 현재 사건의 저장 계약은 이 파일 한 곳에서 정의한다.

```ts
export type CurrentGame = {
  format: 1;
  n: number; seed: string; marks: Record<string, string>; brush: string; accused: string;
  result: 'correct' | 'wrong' | null; attempt: number;
  revealed: boolean; peeked: boolean; earned: number;
};
export type CurrentGameRead = { game: CurrentGame | null; error: 'invalid' | 'storage' | null };
export function parseCurrentGame(raw: unknown): CurrentGame | null;
export function readCurrentGame(): CurrentGameRead;
export function saveCurrentGame(game: CurrentGame): boolean;
```

- [ ] **1. 순수 검증 함수의 실패 검사 작성.** 아래 유효한 기본값을 테스트 안에 둔다.

```ts
const saved = { format: 1, n: 7, seed: 'ux-resume-check', marks: { '0,0': 'A' },
  brush: 'A', accused: '', result: null, attempt: 0, revealed: false, peeked: false, earned: 0 };
expect(parseCurrentGame(saved)).toEqual(saved);
expect(parseCurrentGame({ ...saved, marks: { '7,0': 'A' } })).toBeNull();
expect(parseCurrentGame({ ...saved, peeked: 'false' })).toBeNull();
expect(parseCurrentGame({ ...saved, revealed: true })).toBeNull();
expect(parseCurrentGame({ ...saved, format: 999 })).toBeNull();
expect(parseCurrentGame({ ...saved, marks: { '0,0': 'X' } })).not.toBeNull();
```

- [ ] **2. `npx vitest run src/game/currentGame.test.ts`에서 실패 확인 후 검증을 구현한다.**
  객체인지 확인하고 배열은 거부한다. `n`은 기존 `DIFFICULTIES`에 포함된 정수여야 한다.
  시드는 비어 있지 않은 64자 이내 문자열, 좌표는 `0 <= r,c < n`, 메모 개수는 `n*n` 이하로 제한한다.
  좌표 키는 `${r},${c}` 형식의 정규 문자열이어야 한다.
  길이 상한은 `history.ts`의 기존 `MAX_SEED_LEN`을 export해서 공유한다.
  인물 ID는 `A`부터 해당 난이도의 용의자 수만큼과 `V`, 브러시는 여기에 `X`를 허용한다.
  메모 값도 인물 ID와 `X`를 허용한다. 지목 후보는 용의자 ID 또는 빈 문자열이다.
  판정은 타입의 3가지 값, 횟수는 음수가 아닌 안전한 정수, 점수는 `0..SCORE_BASE[n]` 정수로 검사한다.
  플래그는 boolean이어야 한다. `correct`/`wrong`에는 1회 이상의 시도가 필요하고 미해결 점수는 0이다.
  `revealed`에는 `peeked` 또는 `correct`가 필요하다. 미검증 객체를 타입 캐스트해서 반환하지 않는다.
- [ ] **3. 저장을 구현한다.** 키는 `murdoku.current`, 형식 식별자는 `format: 1`이다.
  JSON 해석 실패는 `invalid`, 저장 공간 접근 예외는 `storage`로 명시적으로 반환한다.
